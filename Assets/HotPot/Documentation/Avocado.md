# Quả bơ / Avocado

VI: Nguyên liệu `Avocado = 24`, tên hiển thị Bơ. Ảnh thô là nửa quả bơ còn hạt; sau sơ chế là các lát bơ xếp quạt. Hai ảnh RGBA trong suốt nằm tại `Assets/HotPot/Art/Sprites/Foods/Sushi/Raw/avocado.png` và `Assets/HotPot/Art/Sprites/Foods/Sushi/Prepared/avocado.png`. FoodIconConfig đăng ký đủ hai trạng thái; công cụ tự điền tìm theo tên avocado. Bơ dùng nhóm Vegetable và Cut/Action mặc định.

EN: Avocado (24) has raw pit-in-half and prepared fanned-slice sprites in the Sushi Raw/Prepared folders. FoodIconConfig registers both transparent sprites; its fill tool resolves the avocado filenames. Preparation uses the default Vegetable category and Cut/Action.

VI: Tool web có Bơ trong thư viện, bộ chọn nguyên liệu, board và tổ hợp order. Giữ nguyên mọi công thức cũ, đặc biệt món Xiên gà teriyaki vẫn chỉ gồm gà và sốt. Chưa thêm công thức món hoàn chỉnh mới chứa bơ; tổ hợp chưa khớp công thức vẫn là bản nháp như cơ chế hiện có.

EN: The web studio includes avocado in the library, selectors, board and order combinations. Existing recipes remain unchanged; teriyaki chicken still requires only chicken and sauce. No new final-dish recipe containing avocado is introduced; unmatched combinations retain the existing draft behavior.

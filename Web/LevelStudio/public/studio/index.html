FOODPOP / LEVEL DESIGN

Level Studio

Thiết kế từng ô. Cân bằng từng order.

Unity .asset tương thích • Cột dữ liệu giữ thứ tự trái → phải, ô giữ thứ tự trên → dưới.

Cách sử dụng

1. Chọn level mẫu hoặc nhập file LevelConfig .asset của bạn.

2. Chọn nguyên liệu, bật cọ để tô board; hoặc chọn từng ô để chỉnh. Kéo thả để đổi chỗ hai đĩa đơn.

3. Ở tab Order khách, chọn loại khách và các nhóm nguyên liệu theo một hàng khách chung.

4. Phần kiểm tra cân bằng trong tab Board & nguyên liệu đối chiếu từng loại nguyên liệu, đĩa đôi và liên kết. Khắc phục lỗi trước khi xuất.

5. Xuất file .asset rồi thay nội dung file config trong Unity. Giữ file .meta của level để bảo toàn GUID.

Bấm Lưu để lưu level lên web và ghi lịch sử theo tài khoản. Bản nháp vẫn tự lưu trên máy; thư viện Level dùng chung dùng để tải bản mới của người khác.
